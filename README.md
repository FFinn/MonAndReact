## Как читать доказательства

В отчёте UTC; на скриншотах Kibana UTC+5. Окно инцидента 11:07–11:12 UTC 06.11.2026. Действия расследователя начинаются с 11:13 UTC. Ночной интервал из легенды не представлен в новых данных. Время внутри CRI-строки является временем события; `@timestamp` этого источника на стенде отражает доставку.

Ссылки `127.0.0.1:15611` работают только при активном SSH-туннеле к DSO-11 и запущенной ВМ; в отчёте есть автономные скриншоты и выборки. Репозиторий не содержит паролей, приватных ключей, полного исходного audit-архива или содержимого Kubernetes Secrets. Подозрительный workload при сборе оставлен для сохранения доказательств; это не отчёт об устранении инцидента.
